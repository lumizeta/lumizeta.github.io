How to install
  1. Tap Download APK and let the download finish.
  2. Open the file from the notification or your Downloads folder.
  3. If Android blocks it, allow Install unknown apps for your browser (Settings › Apps › your browser › Install unknown apps), then open the file again.
  4. To update, install the new build over the old one.
